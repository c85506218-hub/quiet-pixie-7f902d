## 檔案結構

```
index.html                          網站本體（單一檔案，含地圖、資料、樣式）
data/village_map.csv                650 個里 → 分隊 對照表
data/staff.csv                      52 個分隊的人員數 ← 人事異動時改這裡
scripts/update.py                   每月更新腳本
.github/workflows/update-population.yml   自動排程
```

## 資料怎麼來的

| 項目 | 來源 | 更新方式 |
| --- | --- | --- |
| 各里人口數 | [內政部戶政司開放資料 ODRP013](https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP013/11507?page=1) | **每月自動抓** |
| 里 → 分隊 對照 | 消防局《轄區參考表》 | 轄區調整時才改 |
| 分隊人員數 | 局內編制表 | 人事異動時人工改 |

分隊服務人口 = 該隊所轄各里人口相加。
服務人口比 = 該隊服務人口 ÷ 人員數（網頁即時計算，不存死值）。

## 每月更新怎麼跑

每月 **10 日 09:17（台北時間）** 自動執行：

1. 讀 `index.html` 目前的資料月份
2. 問戶政司有沒有更新的月份 —— **沒有就什麼都不做**
3. 有的話：抓村里人口 → 套對照表 → 算出各分隊服務人口
4. 內容真的有變才 commit，並開一個 issue 通知
5. 對不上帳（缺里、多里、人員數為 0、總數不符）就**不寫入網站**，改開 issue 說明哪裡要修

也可以隨時到 **Actions → 每月更新人口資料 → Run workflow** 手動觸發。
改 `data/` 底下的檔案（例如更新人員數）會自動重算，不必等到 10 號。

## 人數的正本在 Google 試算表

**[臺南市消防分隊在職人數（地圖資料來源）](https://docs.google.com/spreadsheets/d/1cqcXU6NRTpcRLOl4PAY-zQBTxLTQIRt3RNljAjrA8UM/edit)**

分享設定是「知道連結的任何人／檢視者」——只有擁有者能改，其他人唯讀。

```
在試算表改人數（手機 Sheets App 也行）
        ↓ 立刻
網頁重新整理就是新數字（前端直接讀試算表）
        ↓ 每月 10 號
Actions 把值固化回 data/staff.csv 與 index.html，成為版本控管的存檔
```

網站右下角 **✏️ 編輯人數** 會直接開這份試算表。

標題列的「人數：」會標示目前用的是哪一份：

| 標示 | 意思 |
| --- | --- |
| **試算表同步**（綠字） | 讀到試算表，用的是最新值 |
| **內建值**（灰字） | 讀不到或內容沒過檢查，改用 index.html 內嵌的數字 |

**前端會先檢查再採用**：52 隊要齊、不能重複、人數要是 1〜999 的整數。
任何一項不過就整批不採用、退回內嵌值——Google 掛掉、機關網路擋 Google、
試算表被誤刪或改壞，網站都照常運作，只是數字停在上次固化的版本。
滑鼠移到標示上會顯示是哪裡出問題。

`scripts/update.py` 也會做同一套檢查（見 `data/staff_sheet_url.txt`）。

## 人事異動怎麼改

編輯 `data/staff.csv`，改「人員數」那一欄，commit 即可，剩下的自動完成。

```csv
分隊,人員數,大隊,備註,無里轄區時歸屬區
新營分隊,34,第一大隊,,
南科分隊,22,第四大隊,南科園區,善化區
```

- **備註**：顯示在分隊卡片上的小標籤
- **無里轄區時歸屬區**：像南科分隊沒有戶籍里轄區，指定它顯示在哪一區

## 轄區調整怎麼改

編輯 `data/village_map.csv`，改該里對應的分隊。里代碼是戶政司的 11 碼代碼，
用代碼比對可避免罕用字（例如安南區「公塭里」戶政司實際用造字碼）造成對不上。

## 資料驗證

115 年 7 月資料經三個來源交叉比對，全數一致：

- 內政部戶政司 ODRP013（村里級）
- 內政部戶政司 ODRP014（村里級，另一資料集）— 逐里零差異
- 臺南市政府資料開放平台（區級）— 37 區零差異

全市 1,847,288 人、650 里。
